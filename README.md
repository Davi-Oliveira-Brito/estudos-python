# Estudos de Python

Exercícios e códigos desenvolvidos durante o curso de Python do professor Luiz Otávio Miranda.

## Conteúdo

- **03-fundamentos:** lógica de programação e fundamentos de Python.
- **04-intermediario:** funções, dicionários, módulos e programação funcional.
- **05-orientacao-a-objetos:** classes e programação orientada a objetos.
- **06-modulos-e-bibliotecas:** biblioteca padrão e bibliotecas externas.
